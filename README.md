# Illustrator Studio

Веб-приложение для сборки и редактирования векторных композиций из заранее подготовленных SVG-компонентов. Проект представляет собой клиентское приложение: отдельный backend, база данных и внешние AI-сервисы для работы редактора не требуются.

## 1. Технологический стек

- **Node.js 18+** — среда выполнения и пакетные скрипты.
- **React 18** — интерфейс и состояние редактора.
- **Vite 6** — dev-сервер и production-сборка.
- **SVG** — формат исходных графических компонентов и экспортируемого документа.
- **lucide-react** — интерфейсные иконки.

Версии прямых зависимостей и lock-файл находятся в `package.json` и `package-lock.json`.

## 2. Установка и запуск

Требуется Node.js версии 18 или новее и npm.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминал.

Production-сборка и её локальный просмотр:

```bash
npm run build
npm run preview
```

Основные npm-скрипты:

| Команда           | Назначение                           |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Запуск сервера разработки            |
| `npm run build`   | Сборка приложения в `dist/`          |
| `npm run preview` | Локальный просмотр production-сборки |

## 3. Архитектура проекта

```text
illustrator-studio/
├── public/
│   ├── favicon.svg
│   └── source/                 # исходные и демонстрационные материалы
├── src/
│   ├── data/
│   │   ├── components.json     # каталог SVG-компонентов и их метаданные
│   │   └── backgrounds.js      # SVG-фоны готовых палитр
│   ├── main.jsx                # React-приложение и логика редактора
│   └── style.css               # стили и адаптивная рабочая область
├── index.html
├── package.json
└── package-lock.json
```

### Основные модули

- `src/main.jsx` — инициализация React, состояние холста, добавление и редактирование объектов, слои, история действий, семантический подбор, управление палитрой и экспорт SVG.
- `src/data/components.json` — каталог доступных компонентов. Для каждого элемента хранятся идентификатор, название, категория и SVG-данные; при наличии доступны варианты размеров L и S.
- `src/data/backgrounds.js` — векторные фоны встроенных цветовых схем.
- `src/style.css` — оформление редактора, панелей и адаптивного поведения.
- `public/source/` — исходные и контрольные материалы проекта. Рабочий каталог компонентов загружается приложением из `src/data/components.json`.

## 4. Принцип работы и ограничения

### Редактирование композиции

Редактор работает с объектами из встроенного каталога. Пользователь может добавлять их на холст, перемещать, вращать, дублировать, удалять, менять порядок слоёв, видимость и визуальную роль объекта. Исходная геометрия компонентов не генерируется заново.

### Семантический компоновщик

Компоновщик принимает свободный текст и выполняет локальное сопоставление слов и их словоформ со словарём смысловых связей в `src/main.jsx`. Найденные компоненты ранжируются, после чего на холст добавляется до четырёх элементов по заранее определённым схемам размещения.

Это **rule-based механизм семантического подбора**, а не подключённая генеративная языковая модель. Качество и тематика результатов ограничены словарём и содержимым `components.json`. Если соответствий нет, приложение показывает уведомление и не подставляет произвольную композицию.

### Обработка данных и интеграции

- Внешний backend и API в текущей версии не используются.
- GPT (OpenAI) и Claude (Anthropic) применялись как вспомогательные инструменты при анализе требований и разработке. В runtime приложения запросы к их API не отправляются.
- Текст компоновщика обрабатывается локально в браузере.
- Для работы приложения не нужны API-ключи, OAuth-подключения или переменные окружения.
- В приложении нет серверного аккаунта или синхронизации проектов между устройствами.

## 5. Формат и экспорт

Холст имеет координатную область `1200 × 630`. Экспорт создаёт самостоятельный SVG-документ с соответствующими `width`, `height` и `viewBox`. В документ включаются фон выбранной палитры и видимые векторные объекты с их преобразованиями. Экспортируемый файл можно открыть и продолжить редактировать в совместимых SVG-редакторах, например Figma или Adobe Illustrator.

## 6. Расширение проекта

- Чтобы добавить или изменить графический компонент, обновите каталог `src/data/components.json` и убедитесь, что SVG-разметка, `viewBox`, определения и метаданные корректны.
- Чтобы расширить семантический подбор, добавьте термины и связи с существующими названиями компонентов в словарь `semantic` файла `src/main.jsx`. Не добавляйте ссылки на отсутствующие компоненты.
- Чтобы добавить встроенную цветовую схему, согласованно обновите список палитр и данные SVG-фона в `src/main.jsx` и `src/data/backgrounds.js`.
- При изменении формата компонентов проверьте добавление в библиотеку, отображение на холсте и экспорт SVG.
