# ILLUSTRATOR STUDIO

Веб-редактор композиций из предоставленной библиотеки SVG-объектов. Компоненты извлечены из исходных файлов `Размер L с ID.svg` и `Размер S с ID.svg` и хранятся в `public/library/components.json` как исходная SVG-разметка. Приложение не генерирует новые иллюстративные объекты.

## Возможности прототипа
- библиотека исходных компонентов и поиск;
- добавление SVG-объектов на холст, перемещение, поворот, дублирование и удаление; масштаб каждого отдельного объекта зафиксирован; размер L/S переключает соответствующие исходные версии с разной детализацией;
- список слоёв, видимость, порядок, роль «главный / фоновый»;
- три цветовые схемы из исходных примеров (лавандовая, тёплая/мятная, мятная/контрастная) и загрузка пользовательской палитры (JSON/TXT/SVG с HEX-цветами);
- импорт дополнительного SVG как объекта;
- автоматический смысловой подбор объектов по заголовку/метафоре из локального словаря (эвристический алгоритм, без обращения к внешней LLM);
- экспорт композиции в SVG, без растрирования; имя файла формируется из поля «Название композиции» с безопасной очисткой недопустимых символов и суффиксом размера L/S.

## Запуск локально
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

## Production-сборка

```bash
npm install
npm run build
npm run preview
```

Готовый production-каталог: `dist/`.

Короткая пошаговая демонстрация: [`DEMO.md`](./DEMO.md).

## Архитектура
- `public/source/` — исходные SVG-файлы и поясняющий JPG из тестового архива, сохранённые без изменений.
- `public/library/components.json` и `src/data/components.json` — извлечённые SVG-группы с ID, названием, категорией, L/S-версиями, цветной основной группой и отдельной монохромной фоновой группой. В браузере геометрические границы вариантов уточняются через SVG `getBBox()`.
- `src/main.jsx` — интерфейс, состояние редактора, локальный семантический подбор, манипуляции объектами и экспорт.
- `src/style.css` — интерфейс адаптивной рабочей области.
- SVG-объекты остаются векторными группами; для отображения используются SVG viewBox и SVG transforms. Каждый объект масштабируется одним общим коэффициентом относительно исходного bbox, поэтому сохраняются исходные пропорции и относительные размеры объектов. L/S автоматически переключает соответствующие исходные группы с разной детализацией; фоновая роль переключает объект на монохромную группу из исходника. При экспорте создаётся самостоятельный SVG-документ с вложенными SVG-областями и исходными путями.

## Ограничения прототипа
Семантический подбор сейчас локальный, на основе словаря метафор и ключевых слов: совпадения ранжируются по весу, после чего выбираются до четырёх компонентов из исходной библиотеки и размещаются по заранее заданной схеме. Это не полноценная LLM/AI-модель, а детерминированный rule-based прототип. Для production можно подключить LLM только для анализа метафоры и ранжирования ID существующих компонентов; финальная композиция всё равно должна собираться исключительно из исходных SVG, без генерации новых объектов. В прототипе используются 10 предметных объектов из исходной библиотеки; отдельная кнопка объекта «Фон» не показывается, так как фон холста задаётся выбранной палитрой: книга, телефон, пазлы, монета, наушники, лампа, букет цветов, кошелёк, ручка и папка. Для всех 10 предметных объектов в текущем каталоге присутствуют варианты L и S, а также цветные и монохромные версии. Сохранение проектов в облаке и совместная работа — следующие этапы развития.

## Примеры
В интерфейсе есть три стартовых сценария компоновки: «Собранно», «Под заголовок», «Со смещением». Все три используют только элементы исходной библиотеки и экспортируются в 1200 × 630; вариант L использует более детализированные исходные SVG, вариант S — упрощённые версии из отдельного исходного файла (элементы «Ручка» и «Папка» в исходной S-библиотеке отсутствуют и доступны только в L); оба экспортируются в 1200 × 630.

## Использованные инструменты
- ChatGPT (GPT-6) — анализ задания и структуры SVG, проектирование архитектуры и реализация прототипа.
- React + Vite — интерфейс и сборка.
- SVG — хранение, отображение и экспорт векторных объектов.


## Структура исходных материалов

- `public/source/` — оригинальные файлы тестового задания и контрольные примеры. Это архив исходников, он не отображается в интерфейсе редактора.
- `public/library/` — подготовленная JSON-библиотека компонентов, доступная для загрузки и дальнейшей обработки.
- `src/data/components.json` — та же библиотека, импортируемая редактором на этапе сборки.

Оригиналы в `public/source/` рекомендуется сохранять без изменений: они нужны для сверки извлечённых компонентов и результатов композиции.
