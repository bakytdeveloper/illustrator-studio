# Руководство пользователя Illustrator Studio

Документ описывает работу с интерфейсом редактора: от добавления компонентов до экспорта готовой композиции.

## 1. Запуск приложения

1. Откройте папку проекта в терминале.
2. Выполните `npm install` (при первом запуске или после обновления зависимостей).
3. Выполните `npm run dev`.
4. Откройте адрес, который Vite покажет в терминале.

## 2. Рабочая область

Интерфейс состоит из трёх основных частей:

- **Левая панель** — библиотека компонентов и список слоёв.
- **Центральная область** — холст, на котором собирается композиция.
- **Правая панель** — размер иллюстрации, название, палитра, параметры выбранного объекта и AI-компоновщик.

Холст имеет размер **1200 × 630**. При изменении масштаба меняется только отображение рабочей области, а не размер экспортируемого документа.

## 3. Сборка композиции из библиотеки

1. В левой панели откройте вкладку **«Библиотека»**.
2. Найдите нужный объект через строку поиска или фильтр категории.
3. Нажмите на карточку компонента — он появится на холсте.
4. Повторите действия, чтобы добавить остальные элементы.
5. Если выбран размер S, недоступные для него компоненты будут отмечены как доступные только в L.

В библиотеке представлены 10 типов исходных объектов: пазлы, книга, телефон, наушники, лампа, кошелёк, ручка, папка, монета и букет цветов. Для компонентов предусмотрены исходные SVG-варианты L/S там, где они доступны.

## 4. Автоматическая компоновка по тексту

1. В правой панели найдите блок **«AI-компоновщик»**.
2. Введите тему, заголовок, метафору или краткое описание. Запрос может быть деловым, учебным, бытовым, творческим или развлекательным.
3. Нажмите **«Собрать композицию»**.
4. Проверьте результат на холсте и при необходимости вручную скорректируйте расположение объектов.

Примеры запросов:

- `Подготовка к экзаменам`
- `Музыка и вечерний отдых`
- `Уютный дом и цветы`
- `Подарок для близкого человека`
- `Идеи для творческого проекта`
- `Путешествие на выходных`

**Важно:** компоновщик не создаёт новые иллюстрации и не понимает абсолютно любую тему как полноценная языковая модель. Он подбирает до четырёх объектов из существующей библиотеки по локальному словарю смысловых связей. Если подходящих соответствий нет, появится уведомление с предложением уточнить запрос; случайные элементы не добавляются.

## 5. Перемещение, поворот и редактирование объектов

1. Нажмите на объект на холсте, чтобы выделить его.
2. Перетащите объект мышью, чтобы изменить его положение.
3. Для поворота перетащите круглую ручку над рамкой выделения.
4. Для точной настройки используйте правую панель **«Параметры объекта»**:
    - **Позиция X / Y** — координаты объекта на холсте;
    - **Поворот** — угол в градусах;
    - **Сбросить угол** — вернуть поворот к нулю;
    - **Дублировать** — создать копию выбранного объекта.
5. Роль объекта можно переключить между **«Главный · цветной»** и **«Фоновый · моно»**.

Пропорции исходного объекта сохраняются; произвольное растягивание по ширине и высоте не предусмотрено.

## 6. Управление слоями

1. В левой панели откройте вкладку **«Слои»**.
2. Нажмите на строку слоя, чтобы выбрать соответствующий объект.
3. Используйте стрелки **«Выше»** и **«Ниже»**, чтобы изменить порядок наложения.
4. Нажмите значок глаза, чтобы скрыть или показать объект.
5. Нажмите значок корзины, чтобы удалить объект.
6. Кнопка **«Добавить объект»** возвращает к библиотеке.

## 7. Инструменты холста

- **Выделение** — режим выбора и перемещения объектов.
- **Дублировать** — копирует выбранный объект.
- **Удалить** — удаляет выбранный объект.
- **Сетка** — включает или выключает отображение сетки.
- **− / +** — уменьшает или увеличивает масштаб просмотра.
- **По размеру** — вписывает весь холст в доступную рабочую область. Экспортные размеры остаются 1200 × 630.
- **Отменить / Повторить** в верхней панели — перемещение по истории изменений.
- **Очистить холст** — удаляет все объекты после подтверждения. Действие можно отменить.

При узком окне рабочую область можно прокручивать по горизонтали, чтобы добраться до всех трёх панелей.

## 8. Размер и название композиции

1. В правой панели выберите **«Размер L»** или **«Размер S»**.
2. Укажите название композиции в поле **«Название композиции»**.
3. Выбор размера влияет на используемый вариант компонента там, где в библиотеке есть отдельные SVG-версии. Сам экспортируемый холст сохраняет область 1200 × 630.

## 9. Цветовая палитра

### Готовая палитра

Выберите один из предложенных вариантов в блоке **«Цветовая палитра»**. Цвета применятся к объектам, а фон холста будет соответствовать выбранной схеме.

### Загрузка собственной палитры

1. Подготовьте файл `.json`, `.txt`, `.css` или `.svg` с HEX-кодами цветов.
2. Используйте шестизначный формат `#RRGGBB`, например `#D7CDF5`.
3. Для JSON используйте ключ `colors` и массив цветов:

```json
{
  "name": "Моя палитра",
  "colors": ["#D7CDF5", "#7864D7", "#F9ECB0", "#F9A3AA", "#FFE3E1", "#181817"]
}
```

4. Нажмите **«Загрузить свою палитру»** и выберите файл.
5. Чтобы вернуться к встроенным цветовым схемам, выберите одну из готовых палитр или сбросьте пользовательскую.

Порядок цветов имеет значение: первый цвет используется как фон, следующие — для основных и дополнительных оттенков. Шаблон JSON можно скачать по ссылке под инструкцией загрузки палитры в интерфейсе.

## 10. Экспорт композиции

1. Проверьте расположение и видимость объектов.
2. Укажите название и выберите цветовую палитру.
3. Нажмите **«Экспорт SVG»** в верхней панели.
4. Браузер сохранит файл с названием композиции и суффиксом выбранного размера.
5. Откройте SVG в Figma, Adobe Illustrator или другом редакторе с поддержкой SVG.

Экспортируется самостоятельный векторный документ размером **1200 × 630**. В него входят фон и видимые объекты; скрытые слои не отображаются в итоговом файле.

## 11. Полезно знать

- В редакторе используются только компоненты встроенной библиотеки; загрузка сторонних SVG-объектов в текущем интерфейсе не предусмотрена.
- Компоновщик выполняет локальный подбор и не отправляет текст запроса во внешние AI-сервисы.
- GPT и Claude помогали при разработке проекта, но не подключены к приложению во время его работы.
- Для получения другого результата автоматической компоновки измените формулировку запроса или соберите композицию вручную из библиотеки.
